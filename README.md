# NTB Toolbox

Modulare Windows-Toolbox der Netz, Technik, Büro GbR.

## Enthalten in 0.1.0

- Systeminformationen
- Netzwerkdiagnose
- Winget-Updates
- SFC und DISM
- Temporäre Dateien öffnen
- Gemeinsamer Prozess-Runner mit sauberem `CommandResult`

## Build

```powershell
dotnet build .\src\NTB.Toolbox\NTB.Toolbox.csproj -c Release
```
